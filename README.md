# ระบบการแจ้งซ่อมภายในโรงเรียน

ระบบ Flask + SQLite สำหรับรับแจ้งปัญหาและจัดการงานซ่อมภายในโรงเรียน

## จุดเด่น
- ผู้แจ้งทั่วไป **ไม่ต้อง Login** และไม่ต้องสมัครสมาชิก
- แจ้งซ่อมผ่านหน้าแรกได้ทันที
- ระบบออกเลขที่ใบแจ้งซ่อมสำหรับติดตาม
- ติดตามงานด้วยเลขที่ใบแจ้งซ่อม
- หลังบ้านแยกสิทธิ์ Admin / Teacher / Technician
- มอบหมายช่างและกำหนดวันเสร็จ
- อัปเดตสถานะงานเป็นขั้นตอน
- แนบรูปก่อน/หลังซ่อม
- Comment, ผลการซ่อม และค่าใช้จ่าย
- Export CSV สำหรับ Admin
- พิมพ์ใบแจ้งซ่อม / Save PDF ผ่าน Browser

## ติดตั้ง

```bash
python -m venv venv
```

Windows PowerShell:

```powershell
venv\Scripts\activate
python -m pip install -r requirements.txt
python app.py
```

เปิด `http://127.0.0.1:5000`

## การใช้งาน

### ผู้แจ้งทั่วไป
1. เปิดหน้าแรก
2. กด `แจ้งซ่อมทันที`
3. กรอกชื่อ สถานที่ ประเภทปัญหา และรายละเอียด
4. ส่งใบแจ้งซ่อม
5. เก็บเลขที่ใบแจ้งซ่อม
6. ใช้เมนู `ติดตามงาน` เพื่อตรวจสอบสถานะ

### Admin
เข้าสู่ระบบเพื่อดูภาพรวม มอบหมายช่าง จัดการผู้ใช้ และ Export CSV

### Teacher / บุคลากร
เข้าสู่ระบบเพื่อดูงานที่ตัวเองแจ้งและติดตามงาน

### Technician
เข้าสู่ระบบเพื่อดูงานที่ได้รับมอบหมาย เริ่มงาน และปิดงานพร้อมบันทึกผล
